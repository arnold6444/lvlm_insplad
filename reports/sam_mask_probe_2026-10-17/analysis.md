# SAM 부품 마스크 선행검사: 고정 설정 연결 보류

기존 Dot 컴퓨터의 Colab L4에서 실제 완료·원시 결과 회수·독립 검산했다. SAM-base 고정 사전학습 가중치, 신경망 추가학습0, LVLM/Q1/gold호출0. 고정 유리 애자15장+정상7장 좌우반전, 이미지 인코더22회/마스크 디코더352회, 오류0. 정상 개체 수나 Q2/Q3 정답을 모델에 전달하지 않았다.

자동 필요조건은 모두 통과했다: 정상7/7에서 후보2개 이상, 정상7/7에서 반전 복원 후 IoU .70이상인 후보 비율 .80이상(실측 .833~1.000). 그러나 원본/후보 오버레이 정상7장 전수 육안검토에서 유리 부품2개 이상을 따로 잡았다고 판단한 사진은4/7로, 사전 기준6/7 미달이다. 금속 중심/구조물/배경이 안정적으로 분할되는 경우도 많다. 한 근접사진은 애초에 완전한 유리 디스크가 한 개뿐이라 두 부품 기준 자체가 해당 시야에 적합하지 않은 한계도 확인했다. 사후 기준 완화로 통과시키지 않는다.

따라서 이 고정 후보선택 설정을 부품 대응·LVLM 증거로 연결하지 않는다. 이 결과는 SAM 전체 모델이 InsPLAD에 쓸모없다는 주장이나 실제 부품 수/위치 정확도 평가가 아니다. 후보 수5~37개를 유리 디스크 개수로 부르면 안 된다. 마스크에 GT가 없어서 육안 판단은 가능성 검사이며 정량 정확도가 아니다. Q2누락/Q3미탐 개선·일반화는 이 실험으로 측정하지 않았다.

소스ZIP `aafc2b534a4f2cbd6291dd5bd7452dfa0a72e7388fe5f253939d7e815ab6ec32`, 결과ZIP `4008f01f1459ab1070cddea370094df77c5a2c0c2be111a549f76c97a84eb188` 원격·로컬 SHA256 일치. 원본15장 바이트, 마스크22파일/점수/선택/반전IoU/호출카운터를 CPU로 별도 재검산했다. 모델 로딩 포함 계산121.204초, 이미지별 생성 latency합74.217초(전달·회수 시간 제외). 코드 fixture2/고정ZIP별도프로세스2테스트와 노트북 내장ZIP/AST 확인. 원본 이미지·모든 마스크·단계별 체크포인트 보존.

근거: [SAM-LAD 원논문](https://arxiv.org/html/2406.00625v4)의 물체 대응 구조와 반복물체/분할 단위 한계, [SAM 공식 구현](https://github.com/facebookresearch/segment-anything). 이번 코드는 SAM-LAD 재현이 아닌 해당 전제의 독립 검사다. DCGA/FeatUp/OMM은 구현·효과 검증하지 않았다.

다음 후보는 [CountGD++ 공식 코드](https://github.com/niki-amini-naieni/CountGDPlusPlus)와 [논문](https://arxiv.org/abs/2512.23351)의 개수 세기 전용 가중치·자동 pseudo-exemplar 구조다. 기존 일반 GroundingDINO 박스 검출과의 학습 목표/구조 차이를 확인했다. 아직 InsPLAD 실행·성능 검증 전이며, official code/weights/Colab 호환성·수작업/유료 도구 없는 실행 범위를 먼저 확인하고 하나의 새 가설을 고정한다. 공식 FSCD 설정의 유료 초해상도/별도 합성 예제를 임의로 도입하지 않는다. 연구 Goal과 heartbeat는 계속 ACTIVE다.
