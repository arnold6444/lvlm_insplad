- 따라서 후보 확인은 계약 미충족으로 공식 비교에서 제외한다. 이8건은 답 자체의 모호성/시각 추론 실패를 입증하지 않는다. 사후 파서 수정으로 과거 점수/eligible을 바꾸지 않는다.

## 5. 3번에서 실행할 것

정상 reference + native InternVL + 동결 missing head를 결합한 dev240 실험을 만든다. 새 Q2/Q3 첫 판단은 같은 pinned snapshot으로 생성하고 Q1은 고정한다.

1. Q2는 결함 유형, Q3는 9칸 복수 위치를 직접 판단한다. 첫 판단480호출.
2. 유리 절연체이고 **해당 질문**의 Q2가 누락이 아니거나 Q3가 빈 위치일 때만 판별기를 호출한다. 다른 질문 답은 쓰지 않는다.
3. 도구가 누락 양성일 때만 같은 질문을 한 번 더 검토한다. 같은 사례에 같은 호출 수의 재질문 대조군을 둔다.
4. 도구 음성으로 기존 누락/위치를 취소하지 않는다. Q2 단순 덮어쓰기 대조군도 둬 LVLM 확인의 추가 가치를 비교한다.
5. 판별기는 위치를 주지 않으므로 Q3 영역을 임의 생성하지 않는다. 실제 dev 양성 위치 GT가 없어 위치 정확도는 null이다. 결함 유무/정상 오탐/미탐과 유형/무효/비용을 평가한다.

이미 본 dev이므로 탐색 결과다. 실제 통합 효과는 사용자가 새 코랩을 실행한 뒤 확인한다. 최종 통합 실험의 구현/merge는 실제 효과 검증 완료와 구분한다.
