## 목적과 고정 대상

실제25장 표시 완료: 박스24장, 판단 불가1장. 실제 PR64 후보 확대를 실행했고 박스 정답도 있는20장으로 고정한다. 판단 불가1장/이전 후보 보류1장/이전 경로 밖3장은 제외 이유를 보존한다. 후보의 정답 적중 여부나 새 모델 응답으로 대상을 더 고르지 않는다.

사람 위치 정답을 입력하는 조건은 **원인 진단용 oracle 조건**이다. 이미 탐색한 dev이며 새로운 holdout·실제 Agent·최종 성능이 아니다. 전부 결함 사진이므로 정상 오탐률·특이도·균형 정확도는 계산할 수 없다. 결과가 좋아도 정상 사진에서 안전하다는 결론을 내리지 않는다.

## 세 조건

| 조건 | 확대 부위 | 확인하는 것 |
|---|---|---|
|candidate_grid|기존 동결 가림 후보 최대2칸|새 공통 프롬프트의 비교 기준|
|oracle_grid|사람 박스 중심이 속한 원본 칸|올바른 칸을 선택하면 회복되는가|
|oracle_box|사람 박스에 각 방향 박스 폭/높이의25% 여백, 원본 경계에서 자름|더 큰 부위 표현·문맥으로 회복되는가|

정상 참조/원본/확대판의3이미지, 타일 예산`[3,3,2]`, greedy80토큰, 조건당1회, 최대60회 LVLM이다. 원본·참조는 같은 SHA의 사진이고 모델은 이전과 같은 `OpenGVLab/InternVL3_5-8B` revision `9bb6a56ad9cc69db95e2d4eeb15a52bbcac4ef79`이다. 양자화·DINO 특징 계산·재학습·임계값 변경·Q1/Q2/gold 추론은 없다.

확대판은 항상1024×548, 두 개의512×512 영역으로 만들며 박스 비율을 보존한다. 사진이 한 개면 남은 영역은 흰색으로 비운다. 같은 위치의 별개 박스는 box 조건에서 각각 보존하고 grid 조건은 칸을 중복 제거한다. 이번 실제 데이터는 최대2박스이며 추가 박스를 임의로 버리지 않는다.

**프롬프트는 세 조건에서 완전히 동일하다. 확대판에는 `Target detail 1/2`만 적고, 정답 칸 번호·박스 좌표·정답 유무·조건 이름을 넣지 않는다.** 원본 Image2에서 위치를 판단하게 한다. GT는 crop 픽셀 선택에만 쓰고 실제 crop 좌표는 감사용 파일에 보존한다. 따라서 사람이 고른 부위라는 정보는 여전히 진단 입력이며 배포 가능한 위치 도구와 혼동하지 않는다.

원본9칸 JSON 응답을 기존 파서로 평가한다. 정답 위치 하나 이상 적중/모든 정답 위치 포함/정답 칸 집합 완전일치, 칸 precision/recall, 유무 회복·빈 답·무효를 나눠 저장한다. 같은20장끼리 paired bootstrap2000회로 진단 차이의 불확실성을 표시한다. GT box 조건은 위치·크기·문맥이 함께 달라지므로 순수 위치 선정 효과라고 주장하지 않는다.

이전44회 응답은 프롬프트와 확대판 설명이 달라 설명용 캐시 점수로만 저장한다. 이번 후보 조건은 새로 실행하며 다른 두 조건과 정확히 같은 프롬프트/시트 크기/호출 수를 가진다. 조건 순서는 이미지 ID 해시로 세 순서를 순환한다.

## 저장·재개·오류

`calls.json`에 raw/prompt/입력 SHA/요청 hash/모델 오류/파싱 결과, `crop_manifest.json`과 `crops/`에 실제 확대판·원본 경계, `dataset_snapshot.json`에 고정 대상과 제외 이유, `metrics_*.json`·`leaderboard.csv`·`paired_diagnostic.csv`·`predictions.json`에 결과를 저장한다. `run_metadata.json`에 GPU/소프트웨어/모델·코드·입력 SHA/새 호출과 재사용 수, `run_status.json`에 완료/오류/무효 수를 남긴다. 결과 ZIP에는 실행 소스·실제 표시 원본이 포함되고 원본 데이터 사진은 제외된다.

동일 코드/모델/입력/폴더에서는 성공 기록을 재사용한다. 무효 응답은 오답으로 유지하고 다시 묻지 않는다. 실행 오류만 이력을 남기고 재시도하며, 오류가 있는 조건은 비교에서 제외한다. 원본 이미지/소스/요청/파싱/crop 조작은 중단한다. 모델 로드 실패나 OOM 후에는 추가 모델 로드를 반복하지 않는다. 오류 때도 마지막 저장 셀로 ZIP을 내보내고 `complete`와 return code를 확인한다.

## 결과에 따른 다음 행동

- 정답 칸에서 회복: 위치 후보 선정 문제의 근거다.
- 정답 박스에서만 회복: 부위 크기/주변 문맥 문제도 남아 있다.

어느 경우에도 이것으로 최종 연구가 끝나지는 않는다. 개선 구조를 dev에서 정하고 정상 오탐을 검증한 뒤, 별도 고정 최종 평가가 필요하다.
