## 범위와 표시 기준

기존 fixed dev240의 missing-cap25장을 모두 표시한다. PR64 실패 사례23장만 고르는 것이 아니라 기존 검출/무효 사례도 포함한다. **새 독립 holdout이 아니다.** 모델 답/가림 후보/점수/정답 칸/파일명은 표시 화면에 보내지 않고, 새 원본 사진에서 사람의 위치 판단을 수집한다. 이전 gold119장 표시, 원본 QA, Q1/Q2 및 기존 결과를 변경하지 않는다.

- 빠진 유리 원판/부품의 연결부, 노출된 금속 몸통 등 누락을 보여주는 부분을 박스로 감싼다. 전체 절연체 줄을 크게 감싸지 않는다.
- 실제로 여러 곳이 빠졌으면 각각 박스를 그린다. 여러 박스는 여러 실제 결함을 의미한다. 애매한 대안 위치를 두 곳 모두 정답으로 넣지 않는다.
- 위치를 정하기 어렵다면 **위치 판단 불가 + 사유**, 누락이라는 원본 라벨 자체에 동의하기 어렵다면 **누락 라벨 이견 + 사유**를 선택한다. 두 상태 모두 위치 unknown이며 정상 정답/빈 정답으로 변환하지 않는다.
- 각 박스 중심으로 원본 전체3×3의 칸을 계산해 중복 없이 정렬한다. 여러 결함 위치를 평균내지 않는다. 박스 자체도 모두 보존한다.

## 저장·재개

원본 해상도 이미지에서 화면 맞춤/원본 크기/확대·축소 및 스크롤로 이동할 수 있다. 9칸 안내선은 선택 사항이며 모델의 후보 표시가 아니다.

박스를 완성하거나 삭제할 때, 메모 입력 후 잠시 멈출 때 Drive에 **초안**이 자동 저장된다. **저장 후 다음(Enter)**으로 확정한다. 초안은 공간 정답으로 집계하지 않는다. 기존 확정 사진을 수정하면 초안으로 돌아가므로 다시 확정해야 한다. 이전 버전은 history에 보존한다.

`초안 저장됨` 표시를 확인한 뒤 나가면 같은 파일/같은 폴더에서 저장한 박스를 복원한다. 다음에 표시 화면을 실행하면 첫 미확정 사진으로 이동한다. 아직 그리는 중인 박스·서버 저장 응답을 못 받은 변경은 보장하지 않는다. 저장 오류는 재시도 버튼으로 확인하고, 다른 탭에서 버전이 바뀌었으면 현재 다시 불러오기로 마지막 서버 상태를 확인한다. 변경을 조용히 덮어쓰지 않는다.
