## 이번에 바꾸는 것

실제 PR63 결과에서 Q2는 직접 결합이 가장 좋았으나, Q3 도구 양성 검토23회(누락22/정상1)가 모두 빈 위치를 유지했다. 다음 실험은 같은23장에 부위 확대 증거를 추가한다. Q2 또는 정답으로 라우팅하지 않는다. Q1/Q2/gold 추론0이며 기존 결과를 덮어쓰지 않는다.

1. 기존 Q3 빈 집합 + glass-insulator + 동결 판별기 양성인 동일23장을 선택한다. 초기 위치가 이미 있는 사진과 초기 무효 출력은 그대로 유지한다.
2. 전체 원본의 각9칸을 흐리기와 해당 칸 평균색으로 각각 가린다. 같은 동결 DINOv2/head로 특징18개를 계산한다. 기존 원본 특징은 PR63의 SHA 검증된 값을 쓴다.
3. `원본 missing logit − 가린 사진 missing logit`을 구한다. sigmoid 포화 때문에 확률차 대신 logit차를 사용한다. 두 방식 모두 양의 차인 칸만 허용한다. 각 방식의9칸 차이를 L2로 정규화한 뒤 두 값의 최소값으로 순위를 매겨 최대2칸을 선택한다(동률은 번호순).
4. 양의 공통 후보가 없으면 두 새 조건 모두 보류하고 초기 답을 유지한다. 후보가 있으면 원본의 해당 칸을 그대로 잘라 확대한다. 가린 사진을 LVLM에 넣지 않는다.
5. LVLM이 정상 참조/전체 원본/확대 crop sheet의3이미지로 Q3를1회 재판단한다. 원본의9칸 좌표로 답하며 후보 밖 위치나 빈 집합도 허용한다.

가림에 따른 출력 변화로 중요 부위를 추정하는 일반 원리는 [Captum 공식 Occlusion 문서](https://captum.ai/api/occlusion.html)에 설명되어 있다. 이 구현은 추가 Captum 의존성 없이 PIL과 동결 분류기로 수행하는 사전 고정 변형이다. **분류기 중요도는 결함 위치 정답이 아니다.** 배경, 정상 부품, 경계 인공물에 반응할 수 있다. 두 가림 방식의 일치는 민감도 확인일 뿐 정확성 보증이 아니다. 지도학습 이력이 있는 판별기이며 training-free 방법이라고 부르지 않는다.

## 대조군과 실행 예산

| 조건 | 입력/처리 |
|---|---|
| cached_direct | PR63의 Q3 최초 답 그대로 |
| cached_cue_review | PR63의 위치 정보 없는 도구 제안 재검토 답 그대로 |
| fixed_crop | 같은23장 중 후보가 생긴 사례에서 고정5,2번 칸을 같은 개수만큼 확대 |
| occlusion_crop | 같은 사례에서 가림 점수가 고른 칸을 확대 |

두 새 조건은 동일한3이미지/타일예산 `[3,3,2]`, 동일 프롬프트 구조, greedy80토큰, 질문당1회다. 실행 순서는 core hash로 교대한다. 최종 비교는 crop 선택+그 좌표 안내의 효과이며, 순수 구조적·인과적 우월성 증명이 아니다. 캐시된 앞선 검토는 입력 수/타일예산이 달라 설명용 비교다.

최대 DINO 특징414회(23×18), 새 LVLM46회(23×2). 두 새 조건이 지도학습 특징 계산을 공유한다. 신규 호출/재사용/오류/무효/실제 GPU·시간은 메타데이터에 남긴다. DINO를 해제한 뒤 LVLM을 로드한다. 모델은 이전과 같은 pinned native snapshot이며 양자화하지 않는다.

## 출력과 해석

`occlusion_maps.json`에 원본/가린 logit, 두 방식의 차이, 순위/선택/보류가 저장된다. `crop_manifest.json`에는 원본 SHA와 픽셀 crop 경계가 있고 `crops/`에는 실제 확대 이미지가 있다. `feature_cache/`와 `features.json`을 ZIP에 포함하므로 저장 특징→동결 head 점수를 독립 검산할 수 있다. 원본 특징·소스·입력도 source capsule에 포함된다.

전체240/자산/결함 유형별 유무 TP/FP/TN/FN·무효율과 paired bootstrap2000회를 출력한다. **양성 위치 GT support0, 위치 정확도null**이다. 미탐 감소만으로 위치 정답을 맞혔다고 주장하지 않는다. 위치 효과를 확정하려면 독립 dev 위치 라벨이 필요하며 이미 탐색한 gold로 튜닝하지 않는다.

기존 무효는 사후 파싱으로 구제하지 않는다. 새 무효는 오답 처리(양성FN/정상FP)하며 유효 답이 나올 때까지 재질문하지 않는다. 추론/특징 오류가 난 새 조건은 비교에서 제외한다. 같은 코드/입력/이미지/모델/폴더의 성공 cache만 재사용하고 오류는 재시도·이력 보존한다. 조작된 요청/특징/원본은 중단한다. 활성23장은 EXIF 회전이 없음을 확인했으며, 다른 EXIF 방향 입력은 좌표 혼동을 막기 위해 거부한다.
